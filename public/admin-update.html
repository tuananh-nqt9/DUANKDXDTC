🎨 Giao diện Admin

Thêm 2 menu mới trong Admin Panel để quản lý nội dung dễ dàng.

🆕 Mới

📋 Hướng dẫn sử dụng:

  • Đăng nhập vào Admin Panel
  • Chọn "Chỉ tiêu phép thử" hoặc "Trang thiết bị" từ menu
  • Nhấn "Thêm mới" để tạo danh mục/thiết bị
  • Upload hình ảnh vào thư mục public/images/equipment/
  • Đặt thứ tự hiển thị và bật "Hiển thị"
  • Nội dung sẽ tự động xuất hiện trên trang chủ và trang chi tiết

⚠️ Lưu ý quan trọng:

  • Chạy lệnh: npx prisma generate để cập nhật database
  • Nếu server đang chạy, restart lại: npm run dev
  • Upload hình ảnh thiết bị vào thư mục public/images/equipment/
